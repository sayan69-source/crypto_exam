Most likely causes

  1. The image has no centre stack. Only the allinone variant carries the Edge, the portals and the database on the stick. A dev or production image expects a separate Centre Edge appliance on the LAN.
  2. The centre stack failed to start. On an allinone image the database, the Edge API, both portals and the proxy start at boot; if one of them fails, nothing binds the origin.
  3. No route to the Edge. On a production terminal the only path to the centre is the WireGuard tunnel; without it the firewall drops everything by design.
